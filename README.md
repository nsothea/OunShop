## 🌟 មុខងារចម្បងៗ (Key Features)

1. **Upload រូបភាពឥវ៉ាន់ (Product Photo)**:
   - អាច Upload រូបភាពឥវ៉ាន់ពីកុំព្យូទ័រផ្ទាល់ (Drag & Drop) ឬដាក់ Link រូបភាព
   - ចុចលើរូបភាពដើម្បីពង្រីកមើលរូបច្បាស់ (Full Image Zoom Lightbox)

2. **Link Taobao / 1688**:
   - រក្សាទុក Link ទំនិញដើមពី Taobao ងាយស្រួលចុចបើកមើលភ្លាមៗ (1-Click Open) ដើម្បី Reorder ឬពិនិត្យព័ត៌មាន

3. **គណនាតម្លៃ និងថ្លៃដឹកជញ្ជូន ចិន-ខ្មែរ (Shipping & Cost Calculation)**:
   - ថ្លៃដើមគិតជាប្រាក់យ៉ន់ (¥) ឬដុល្លារ ($) ជាមួយការប្តូរប្រាក់ស្វ័យប្រវត្តិ
   - ថ្លៃដឹកក្នុងស្រុកចិន (China Domestic Shipping)
   - ថ្លៃដឹកពីចិនមកខ្មែរ (Cambodia Shipping / ថ្លៃគីឡូ)
   - តម្លៃលក់ចេញជូនភ្ញៀវ
   - គណនាចំណាយសរុប ចំណូលសរុប និងប្រាក់ចំណេញសុទ្ធភ្លាមៗ

4. **ព័ត៌មានអតិថិជន (Customer Information)**:
   - ឈ្មោះភ្ញៀវ លេខទូរស័ព្ទ Contact (Facebook / Telegram / TikTok)
   - អាសយដ្ឋានដឹកជញ្ជូន
   - កត់ត្រាប្រាក់កក់ និងប្រាក់នៅសល់ដែលត្រូវទូទាត់

5. **ថ្ងៃមកដល់របស់ឥវ៉ាន់ (Arrival Tracking)**:
   - កាលបរិច្ឆេទឥវ៉ាន់មកដល់
   - ប្រព័ន្ធបង្ហាញការរាប់ថយក្រោយស្វ័យប្រវត្តិ (ឧ. "នៅសល់ ៣ ថ្ងៃ", "មកដល់ថ្ងៃនេះ!", "បានមកដល់...")

6. **ស្ថានភាពដឹកជញ្ជូនជូនភ្ញៀវ (Delivery Status)**:
   - 🟡 **រង់ចាំឥវ៉ាន់មកដល់** (Waiting for Arrival)
   - 🔵 **ឥវ៉ាន់មកដល់ហើយ / ត្រៀមផ្ញើ** (Arrived)
   - 🟢 **បានផ្ញើជូនភ្ញៀវរួចរាល់** (Shipped to Customer)
   - 🟣 **បានបញ្ចប់ / ទូទាត់រួច** (Completed)
   - ❌ **បានបោះបង់** (Cancelled)
   - អាចចុចប្តូរស្ថានភាពបានភ្លាមៗពីផ្ទាំងខាងមុខ (Quick 1-Click Status Switcher)

7. **ស្ថានភាពស្តុក (Stock Status)**:
   - ⏳ **កុម្មង់ទុកមុន (Pre-order / អត់ស្តុក)**
   - 📦 **មានក្នុងស្តុកស្រាប់ (In Stock)**
   - ❌ **អស់ពីស្តុក (Out of stock)**

8. **របាយការណ៍ហិរញ្ញវត្ថុ & ចំណូលចំណាយ (Financial Dashboard)**:
   - កាតសង្ខេប៖ ចំណូលសរុប, ចំណាយសរុប (បំបែកថ្លៃទំនិញ ដឹកចិន ដឹកខ្មែរ), ប្រាក់ចំណេញសុទ្ធ, និង Margin %
   - ក្រាហ្វ និងតារាងស្ថិតិប្រចាំខែ
   - ស្វែងរក (Search) និង Filter តាមស្ថានភាព និងកាលបរិច្ឆេទ
   - ប្តូរទិដ្ឋភាពបាន ២ បែប៖ **Cards View (កាតរូបភាព)** ឬ **Table View (តារាង Excel)**

9. **បង្កាន់ដៃវិក្កយបត្រ (Invoice / Receipt)**:
   - ចេញបង្កាន់ដៃស្អាត មានរូបទំនិញ តម្លៃ ប្រាក់កក់ និងព័ត៌មានហាង ដើម្បី Print ឬ Screenshot ផ្ញើជូនភ្ញៀវតាម Telegram/Messenger

10. **Export ទៅកាន់ Excel / CSV**:
    - ចុចប៊ូតុង `Export Excel` ដើម្បីទាញយកទិន្នន័យទាំងអស់ជាឯកសារ Excel (គាំទ្រអក្សរខ្មែរ ១០០%)

## 🚀 របៀបបើកដំណើរការ (How to Run)

### វិធីទី១៖ ងាយស្រួលបំផុត (Double Click)
- គ្រាន់តែចុចពីរដង (Double click) លើ File **`start.bat`** នោះប្រព័ន្ធនឹងបើកដំណើរការ Server ហើយបើក Browser បង្ហាញកម្មវិធីនៅ `http://localhost:5000` ដោយស្វ័យប្រវត្តិ។

### វិធីទី២៖ តាមរយៈ Terminal / Command Line
```bash
# នៅក្នុង Folder d:\Oun_Shop\System
node server.js
```
រួចបើក Browser ទៅកាន់អាសយដ្ឋាន៖
👉 **http://localhost:5000**
